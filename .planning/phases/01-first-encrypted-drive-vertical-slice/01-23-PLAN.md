## Trust Boundaries

| Boundary | Description |
|---|---|
| TLS connection → route identity | Bootstrap, administrator, and active-device routes need different peer-certificate requirements without header spoofing or bearer downgrade. |
| Both DCs + remote CIM → trusted provisioning | Directory identity and endpoint hardware must be collected by LAB-DC01 over authenticated channels rather than supplied by the future agent. |
| Production environment → server providers | Missing or test providers must prevent migration/listener startup rather than silently selecting in-memory state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-23-01 | Spoofing/Elevation | TLS/route partition | high | mitigate | Bootstrap-only optional peer, distinct administrator/device issuers, active-serial lookup, and no forwarded identity/header fallback. |
| T-01-23-02 | Spoofing | directory corroboration | high | mitigate | Explicit independent DC hostname queries, equal enabled identity, bounded timeout, and deny on single/disagreeing result. |
| T-01-23-03 | Spoofing/Tampering | remote hardware collection | high | mitigate | LAB-DC01 role guard, Kerberos WinRM HTTPS/FQDN, exact OS-disk association, fixed normalization, and no agent authority. |
| T-01-23-04 | Information disclosure | provisioning token/admin secrets | high | mitigate | Runtime-provider handoff, no argv/stdout/env-file/log/evidence value, allowlisted publication, and leakage tests. |
| T-01-23-05 | Tampering | production composition | high | mitigate | Concrete provider construction and validation before migration/listener binding; no default/test provider path. |
