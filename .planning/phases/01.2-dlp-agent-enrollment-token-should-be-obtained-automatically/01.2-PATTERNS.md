```powershell
function Invoke-Openssl([string]$Arguments) {
    $psi = New-Object System.Diagnostics.ProcessStartInfo('openssl', $Arguments)
    $psi.RedirectStandardOutput = $true
    $psi.RedirectStandardError = $true
    $psi.UseShellExecute = $false
    $psi.CreateNoWindow = $true
    $proc = [System.Diagnostics.Process]::Start($psi)
    $stdout = $proc.StandardOutput.ReadToEnd()
    $stderr = $proc.StandardError.ReadToEnd()
    $proc.WaitForExit()
    if ($proc.ExitCode -ne 0) {
        Stop-Generation 'openssl_failed' "openssl $Arguments`n$stderr"
    }
    return $stdout
}
```

## Shared Patterns

### Native Process Safety

**Sources:** `scripts/lab/Invoke-TrustedProvisioning.ps1:233-254`, `scripts/lab/New-DlpPhase1RootCa.ps1:16-29`

**Apply to:** `Invoke-AuthorityQuery` and its deterministic probe.

- Resolve the executable explicitly.
- Pass a deliberate argument sequence with the database URL last.
- Capture stdout and stderr independently.
- Reject non-zero exit and any non-empty stderr/warning output.
- Clean temporary output files in `finally`.
- Emit only stable error codes; never include the database URL or raw authority data.
