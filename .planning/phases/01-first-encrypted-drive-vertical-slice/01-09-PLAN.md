## Trust Boundaries

| Boundary | Description |
|---|---|
| Local backing filesystem → recovery | Attacker/crash can alter, remove, replay, reorder, truncate, or substitute any persisted artifact. |
| Durability operation → restart | Process/machine loss can occur before or after every write/flush/replace. |
| Integrity failure → diagnostics/evidence | Failure handling itself can leak plaintext or destroy forensic material. |

| T-01-29 | Tampering/Denial of service | crash consistency | high | mitigate | Fault injection around every durability step, fresh-process reopen, idempotent cleanup, old/new complete invariant. |
