## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Silent host exit due to missing pipe | `dlp-drive-host.exe` exits with code 2 when the pipe does not exist, but the service only logs `session_logon succeeded`. | blocking | Service must call `ActorPipe::create` **before** `CreateProcessAsUserW` and keep the pipe instance alive until the child connects. |
| Stale deployed binaries | Previous `dlp-windows-service.exe` predated fixes and masked the real problem. | blocking | Compare deployed binary SHA-256 to `target/release/*.exe` before runtime debugging. |
| Overlapped pipe I/O complexity | Current host uses `FILE_FLAG_OVERLAPPED`, but the new `ActorPipe` is synchronous. | advisory | Switch host to synchronous `CreateFileW` in this iteration; overlapped can be added later if needed. |
