## Trust Boundaries

| Boundary | Description |
|---|---|
| WTS/SCM event + token → session actor | Event order and token identity determine user/store authority. |
| User-session host → service-owned named pipe | Forged, stale, wrong-user, or malformed clients may attempt to cross identity/store boundaries. |
| Sign-out/restart → keys, mount, and store | Races can leave mounts, handles, credentials, or partial data active. |

| T-01-15-02 | Spoofing/Elevation | storage IPC | high | mitigate | Service-owned DACL plus connecting SID/session/PID/generation validation and bounded versioned messages. |
