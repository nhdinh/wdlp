## Trust Boundaries

| Boundary | Description |
|---|---|
| local JSON config -> privileged service | Locally stored IP and folder authorization data controls a remote file-read surface. |
| HTTP query -> filesystem | Untrusted path and line-count input reaches canonicalization and bounded file I/O. |
