<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Virtual filesystem inputs → `VirtualPath`/store | Names, lengths, offsets, flags, and concurrency are attacker-controlled. |
| Store key → AEAD record writer | Nonce/key reuse or unauthenticated metadata breaks confidentiality/integrity. |
| Backing filesystem → recovery/read | Every local file, directory entry, length, and timestamp is untrusted/tamperable. |
| Buffered write → durable commit | Crash/disk-full may separate data, metadata, and publication. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-21 | Elevation of privilege | `VirtualPath`/store selection | high | mitigate | Parse/bound components, reject traversal/device/UNC/ADS/reparse forms, derive host path from captured SID/store/file IDs only. |
| T-01-22 | Tampering | untrusted backing records | high | mitigate | Bound and authenticate commit/manifest/chunks/AAD before decode; never trust host metadata/order/names. |
| T-01-23 | Tampering/Information disclosure | AEAD nonce/AAD | high | mitigate | OS-random persisted 96-bit nonce, per-generation duplicate rejection, version/store/file/generation/kind/index/length AAD. |
| T-01-24 | Tampering/Denial of service | commit/recovery | high | mitigate | Unreferenced staging, ordered flushes, authenticated commit, atomic pointer, exhaustive fault injection, prior-commit preservation. |
| T-01-25 | Information disclosure | plaintext/key artifacts | high | mitigate | Encrypt content/sensitive metadata, secrecy/zeroize keys, zero plaintext temp files, recursive non-vacuous marker scan. |
| T-01-26 | Repudiation | integrity diagnostics/evidence | medium | mitigate | Preserve encrypted evidence unchanged and log only stable code, opaque record ID, digest, correlation ID. |
| T-01-27 | Denial of service | file/directory operations | medium | mitigate | Bound paths/components/records/handles, per-file locking, typed no-space errors, no partial publication. |
| T-01-SC | Tampering | Cargo packages | high | mitigate | Use only audited or explicitly approved exact Cargo.lock packages and run slopcheck before accepting the crypto/storage dependency graph. |
</threat_model>
