**As an** authorized Windows user, **I want to** have protected-drive operations evaluated against assigned policy with clear feedback, **so that** sensitive files remain inside the organization's DLP boundary.

<objective>

Purpose: The evaluator becomes a DLP boundary only when denial precedes plaintext release and durable/namespace mutation.
Output: Authenticated digest migration, candidate transaction, complete callback enforcement, stable status, and synchronous event handoff.
</objective>
