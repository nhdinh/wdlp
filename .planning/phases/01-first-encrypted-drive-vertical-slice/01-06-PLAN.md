## Trust Boundaries

| Boundary | Description |
|---|---|
| Endpoint/admin → enrollment authority | Token and locally observed hardware identity are untrusted. |
| Server → two AD DCs | Directory server identity and replicated attributes require independent authentication/agreement. |
| Agent CSR → online device issuing CA → enrollment response/repository | CSR validation, constrained issuance, serial status, and revocation determine device authority; the endpoint private key never crosses this boundary. |
