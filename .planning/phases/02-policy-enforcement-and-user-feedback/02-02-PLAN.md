| Boundary | Description |
|---|---|
| Admin/auditor mTLS peer -> routes | Verified certificate identity becomes a persisted role; request role claims are untrusted. |
| Routes -> PostgreSQL | Concurrent drafts, versions, assignments, and status cross the transactional authority boundary. |
| Device mTLS peer -> selection/status | Device identity must come from the verified certificate. |
