## Trust Boundaries

| Boundary | Description | Data Crossing |

## Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation | Status |
|-----------|----------|-----------|----------|-------------|------------|--------|
| T-01.1-01 | Information Disclosure | Examples/diagnostics | high | mitigate | `ENV-VARS.md` uses visibly non-runnable sensitive markers, value-redacted checks, and an exposure response that stops copying, removes artifacts, rotates affected material, and resumes with redacted diagnostics. | closed |
| T-01.1-02 | Spoofing | Server URL/root CA | high | mitigate | `ENV-VARS.md` specifies hostname-aware `https://LAB-DC01:8443`, certificate/path and fingerprint checks, inline and absolute-path root CA forms, and the canonical PKI guidance. | closed |
| T-01.1-03 | Tampering | `agent.env`/registry | medium | mitigate | `ENV-VARS.md` identifies both as generated copies, prohibits independent edits, and verifies name-level visibility without revealing values. | closed |
| T-01.1-04 | Tampering | Five omitted overrides | medium | mitigate | The reconciliation documents 15 service-consumed names, 10 runner-persisted names, and the five lifecycle/session overrides that retain service defaults under SCM. | closed |
| T-01.1-05 | Repudiation | Troubleshooting | low | accept | Documentation cannot enforce operator behavior; stable error identifiers and repeatable redacted checks provide proportionate traceability. | closed |
| T-01.1-SC | Tampering | Package installs | high | mitigate | Phase commits modify documentation only and introduce no dependency or package installation. | closed |
