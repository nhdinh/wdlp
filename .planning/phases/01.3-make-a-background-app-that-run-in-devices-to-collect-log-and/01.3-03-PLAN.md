<interfaces>
Configuration schema:
- `version`: integer `1`
- `trusted_client_ips`: array of exact IP address strings
- `allowed_folders`: array of absolute existing folder strings; only direct children are authorized
- `port`: nonzero TCP port, default `9191`
- `max_response_bytes`: positive hard cap, default `262144`

Runtime contracts:
- Service name: `DlpLogDebugService`
- Default config: `C:\ProgramData\DlpLogDebugService\config.json`
- Endpoint: `GET /logs?path=<absolute-path>&tail=<positive-line-count>`
- Success: 200 and source text only
- Primary errors: `invalid_tail`, `invalid_path`, `untrusted_client`, `forbidden_path`, `file_not_found`, `read_failed`
</interfaces>
