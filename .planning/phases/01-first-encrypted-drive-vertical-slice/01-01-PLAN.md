<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| CLI/test client → versioned server router → PostgreSQL | Untrusted JSON and bearer material cross into authoritative persisted state. |
| Signed bytes → agent activation cache | Untrusted/downloaded bytes may attempt tamper, rollback, replay, or schema confusion. |
| Filesystem port → encrypted backing directory | Untrusted path/content becomes persisted ciphertext and later plaintext. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Tampering | `ConfigurationActivator` | high | mitigate | Verify Ed25519 strictly over canonical bytes, key id, schema, hash, and monotonic bundle version before staging; atomic pointer update retains current/LKG. |
| T-01-02 | Tampering | AEAD record writer | high | mitigate | Generate and persist a unique 96-bit nonce per key/record, bind identity in AAD, reject duplicate key/nonce insertion, and authenticate before decode. |
| T-01-03 | Information disclosure | backing artifacts/diagnostics | high | mitigate | Encrypt content and sensitive metadata; use secrecy/zeroize types after approval; scan backing artifacts/log capture for plaintext markers and secrets. |
| T-01-04 | Elevation of privilege | portable/Windows boundary | medium | mitigate | Forbid unsafe in portable crates, isolate FFI to two Windows crates, and require safety comments plus clippy. |
| T-01-05 | Denial of service | JSON/file inputs | medium | mitigate | Bound request, path, component, and record sizes and return typed errors without partial activation/commit. |
| T-01-SC | Tampering | Cargo dependencies | high | mitigate | Use the research audit for OK packages and a blocking human legitimacy checkpoint for SUS/ASSUMED packages before manifest or lockfile commitment. |
</threat_model>
