<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Admin/endpoint → server enrollment | Token, fingerprint, and computer identity can be spoofed/replayed. |
| Server → two AD DCs | Directory server identity/data can be forged or disagree. |
| Server CA/agent DPAPI → mTLS channel | Issuance, local custody, replacement, and revocation determine device authority. |
| Network/cache → active signed bundle | Tamper, replay, rollback, truncation, and concurrent completion are hostile. |
| Applications/WinFsp → path/store | Filesystem names, buffers, flags, sizes, handles, and identity are untrusted. |
| Store durability/recovery → plaintext result | Nonces, crashes, corruption, disk failures, and diagnostics may leak or mix data. |
