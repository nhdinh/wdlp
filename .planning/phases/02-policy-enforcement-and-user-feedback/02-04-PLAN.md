**As an** authorized Windows user, **I want to** have protected-drive operations evaluated against assigned policy with clear feedback, **so that** sensitive files remain inside the organization’s DLP boundary.

<objective>

Purpose: The policy engine is not a DLP boundary unless denials occur before plaintext release or durable/namespace mutation.
Output: Authenticated digest manifest migration, explicit candidate inspection transaction, complete callback enforcement, stable NTSTATUS mapping, and deterministic event handoff.
</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Encrypted selected generation -> ephemeral inspection | Authenticated data becomes bounded plaintext facts and must not become durable. |
| Evaluator decision -> storage/namespace commit | Authorization must precede every externally visible mutation. |
| WinFsp callback -> application buffer/status | A denial must release zero plaintext and only a stable access-denied status. |
