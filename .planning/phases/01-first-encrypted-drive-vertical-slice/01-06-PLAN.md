<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Windows I/O manager/app → WinFsp callbacks | Names, buffers, offsets, flags, handle order, cancellation, and concurrency are untrusted. |
| WinFsp adapter → portable store | Status/order translation must preserve durable and integrity semantics. |
| Installed runtime/crate → service process | Supply-chain and DLL-load behavior can execute native code. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-33 | Tampering/Elevation | paths/callback identity | high | mitigate | Parse bounded `VirtualPath`, captured SID/store only, no host concatenation/caller user ID, explicit ADS/reparse rejection. |
| T-01-34 | Tampering/Information disclosure | read/integrity mapping | high | mitigate | Store authenticates before buffer copy; stable integrity NTSTATUS, zero returned bytes, encrypted evidence retained. |
| T-01-35 | Tampering/Denial of service | flush/close/write | high | mitigate | Await durable commit; typed no-space/short-write/share/cancel status; prior commit unchanged. |
| T-01-36 | Information disclosure | callbacks/diagnostics | high | mitigate | Never log buffers/full paths/raw SID/key; backing scan and captured-log marker tests. |
| T-01-37 | Denial of service | offsets/sizes/concurrency | medium | mitigate | Checked arithmetic, bounded allocation/enumeration/handles, per-file synchronization, cancellation-aware callbacks. |
| T-01-38 | Tampering | WinFsp supply/runtime | high | mitigate | Prior blocking crate approval, exact version/lock, official MSI pinned hash + valid Authenticode signer, documented delay-load helper only. |
| T-01-SC | Tampering | Cargo packages | high | mitigate | Require the 01-01 blocking WinFsp approval, exact Cargo.lock source/version, and slopcheck before the dependency is committed. |
</threat_model>
