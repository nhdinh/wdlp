<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Windows hardware/firmware/device APIs → service | Local values are untrusted observations and may be unavailable or admin-spoofed. |
| Local key/CSR + server enrollment response → DPAPI credential file | The private key stays endpoint-local; CSR and returned constrained certificate chain must be validated before protected storage without leakage. |
| DPAPI/ACL file → agent HTTP client | A stolen, corrupt, or broadly readable blob must not authorize the device. |
| Network bundle bytes → active configuration | Tamper, truncation, rollback, replay, and concurrent completion are hostile. |
