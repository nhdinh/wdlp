<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Internet/LAN endpoint → enrollment API | Token and client-reported hardware/identity claims are untrusted. |
| Server → primary and secondary AD DCs | Directory network responses and server identity must be independently authenticated. |
| Server PKI → endpoint mTLS credential | CA key custody, certificate binding, and revocation determine device authority. |
| Administrator/agent TLS peer → Axum route | Client certificate context must be authenticated and bound to the correct route/device. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-06 | Spoofing | enrollment endpoint | high | mitigate | Single-use expiring token, exact preloaded digest, dual-DC computer agreement, transaction locking, and no MAC authority. |
| T-01-07 | Spoofing/Tampering | AD lookup | high | mitigate | Direct LDAPS to two configured DC hosts with pinned org CA, bounded queries/attributes, referral rejection, and exact GUID/SID/state agreement. |
| T-01-08 | Spoofing | fingerprint provenance | high | mitigate | Admin computes/preloads digest from SMBIOS UUID, BIOS serial, and physical system-disk serial; server records digest only and documents lack of remote attestation. |
| T-01-09 | Elevation of privilege | device certificate issuance | high | mitigate | CA key only from mounted secret; device-ID SAN/clientAuth EKU/random serial/expiry; private key returned once and never server-persisted. |
| T-01-10 | Spoofing | mTLS authorization/revocation | high | mitigate | rustls chain verification plus application lookup of SAN+serial to active device; replacement revokes prior serial transactionally. |
| T-01-11 | Tampering | signed configuration selection | high | mitigate | Immutable canonical bytes, Ed25519 signature/hash/key id/schema, monotonic version repository query, and agent-side replay gate. |
| T-01-12 | Information disclosure | logs/API errors | high | mitigate | Stable codes/correlation IDs only; redact raw serials, tokens, AD bind data, certificates' private material, CA keys, and protected data. |
| T-01-13 | Denial of service | enrollment/readiness | medium | mitigate | Body/attribute/time limits, bounded pools, no state mutation in readiness, and transaction-scoped token locking. |
| T-01-SC | Tampering | Cargo packages | high | mitigate | Require the 01-01 blocking legitimacy approval, exact Cargo.lock versions/source links, and slopcheck review before committing gated dependencies. |
</threat_model>
