## Trust Boundaries

| Boundary | Description |
|---|---|
| Four-machine orchestration → evidence rows | A correct behavior on the wrong machine is invalid evidence and can conceal unsafe deployment. |
| Production trust chain → mounted drive | Enrollment, AD/WinRM, PKI, TLS, DPAPI, signed config, session IPC, WinFsp, and store authentication must all connect without fixture substitution. |
| Failure harness → recovery result | Graceful shutdown, timing errors, or incomplete hashes can falsely certify crash consistency. |
| Product/log files → sanitized evidence | Evidence collection can leak credentials, identity data, paths, or protected content. |
